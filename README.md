One line of weather, 140 characters at most, for a city that does not
exist — written to charm a bored commuter on the way to work. Entered
in the [make.fun](https://make.fun/bounty/u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e?ref=38m33ybw)
"Charm the Commuter: Forecast a City That Isn't" bounty.

## The forecast

> Cloudhaven: light strawberry snow this morning, buses run on time for once, and every commuter gets a free second sunrise before nine.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python standard library. It validates the entry
(one line, non-empty, at most 140 characters) before writing it to
`/output/entry.txt`.
